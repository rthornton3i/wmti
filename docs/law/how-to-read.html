How to read the law pages

Every law page is written by docs/generate_law_pages.py from one law file in .config/law (the same files the model reads in the app), so the pages show exactly the figures the simulation uses. The text in a page’s notes and sources is the file’s own. Each section first states the law in plain words, computed from the file’s figures (nothing is copied by hand): the income tax brackets as one table per bracket table, the deductions, exemptions and exclusions with their amounts, and the other taxes and costs in a sentence or a short table. A line marked How the model uses this then says what the model does with the section and links Model rules by group; the figures as the file stores them follow under As stored in the file.

Bracket tables

A bracket table lists, per bracket, the taxable income it starts over, where it ends (up to the next bracket’s threshold; the last runs and above), its rate, and its base: the tax on all the brackets below, as the file stores it. The tax on an income is the base of its bracket plus the rate times the income over the threshold. The table’s heading names the filing statuses that use it (from the file’s filing_tables); a flat tax has one bracket, and a state without an income tax has one bracket at 0%. Whether the thresholds are indexed is said above the tables.

The law file box

Under the facts at the top of each page, a box names the law file the page is written from (.config/law/<code>.json) and links a copy of it that ships with these pages (_static/law), the same file the model reads. In the html pages the box also holds the income-tax sections of the file as raw JSON, folded: click The income-tax sections as stored (JSON) to open it.

Confidence chips

This is the one definition of the confidence labels; every other page links here. Each section carries the confidence its file records:

  • Confirmed primary: read on a primary source (the tax agency, the statute or the official data).

  • Confirmed secondary: read on secondary sources only (a compiled table such as the Tax Foundation’s or the Census’s, a tax publisher or a news report), usually two that agree; not yet read on the primary source.

  • Unconfirmed: not checked against a source yet (for example recalled or estimated), sources that disagree, or a rule the model can only approximate; these sections sit in a box with a red edge.

  • Not rated: the section carries no confidence label of its own; the file’s source line (in the facts table at the top of the page) says where its figures come from.

A section made of parts (such as state_strategies) shows the weakest of its parts’ labels. On a state page the core income-tax sections (filing_tables, state_base, income_brackets, standard_deduction, exemptions) carry no label of their own and show the state’s income tax confidence instead: the weakest label recorded for its own income tax (the labels of its income-tax sections and Social Security and those named in its source line and their notes; the average local income tax is left out), the same label the table of state law files shows.

Status: final or estimate

This is the one rule for a file’s status; every other page links here. Each law file records its status in its header, set by hand when the file is checked; the pages and the states table show it as the file records it and compute nothing:

  • final: every income-tax figure of the file was checked against the jurisdiction’s own publication for the file’s tax year, and the file was then marked final.

  • estimate: anything else.

Confirmed primary labels on every income-tax section are needed for final but do not make a file final on their own: a file stays an estimate until that check is done and recorded, so many files whose income tax is confirmed primary are still estimates. The living costs (property tax, insurance, car costs, gas, electricity, home values and sales tax) do not count toward the status.

Figures

A rate, percent or share shows as a percent with the fraction the file stores beside it (6.625% and 0.06625). Dollar figures are in the file’s tax year dollars. indexed says whether the model grows a figure with inflation each year; adjustment says how a figure that is not indexed changes (legislated: only a new law changes it). Lists of rows, such as brackets, show as tables, one column per field.

Where the data lives and how it is updated

The law files are .config/law/federal.json and .config/law/<code>.json for each state, listed in .config/law/states.json. They are updated once a year, and these pages are written again from them. Tax law in the model lists the rules the model leaves out.
