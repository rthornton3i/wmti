Using the toolkit

Purpose: for new users, how to open the app and four worked examples, plus the same run from Python.

The app and the Python API give the same results (see The app).

Open the app

The app is one web page: https://rthornton3i.github.io/wmti/ . Nothing is installed and nothing you enter leaves the device. From 1100 px wide, Setup, Inputs and Outputs sit side by side. On a phone, open it once (about 20 MB), then choose Install app in the menu to use it offline.

  • A first visit opens the walkthrough on the example household. Skip for now closes it; Walk me through it… in the menu reopens it.

  • What each tab is for lists what each tab is for. Model rules by group gives each group’s defaults.

  • Every edit reruns the model. A figure marked (%) is a percent: type 3 for 3%.

  • A gray field holds its default. After a change, the circular-arrow button in the field restores it.

Use case 1: a retirement projection

  1. Setup, Household: each person’s age and the home state.

  2. Income: salary and the age pay stops (Income).

  3. Retirement: Social Security benefit and claim age (Social Security).

  4. Expenses, Children and Home: spending, children’s costs, homes or rent (Expenses, Children, Home).

  5. Accounts: every account, and the withdrawal order (Accounts).

  6. Benefits: employer match and yearly deposits (Retirement plan).

  7. Outputs: read the headline figures and the chance of running out (Headline figures).

Use case 2: Traditional or Roth savings

  1. Save the open scenario under a name.

  2. Change Benefits, for example move the deferral into a Roth deposit.

  3. Duplicate it under another name.

  4. Open Compare and pick one as Config A and the other as Config B.

Both run on the same draws. How Compare judges explains the table. To judge a strategy, compare one scenario with it on in Strategies against one with it off.

Use case 3: when to claim Social Security

  1. On Retirement, enter the benefit for two or more claim ages (Social Security).

  2. Save the scenario, change the claim age, and save it under another name.

  3. Open Compare and pick the two.

Use case 4: a loan and an extra payment

  1. In Loans, add the loan with balance, rate, months left and extra monthly payment (Loans).

  2. Save a copy without the extra payment.

  3. Compare the two to see what it saves.

If the payment is already an Expenses row, tick Payment in Expenses.

Using the Python API

Run this from the repository root after pip install -e .:

import dataclasses

from wmti.retirement import compareScenarios, compareTable, loadInputs, runIterations, runOnce

inputs = loadInputs()                       # the shipped default profile
result = runOnce(inputs, seed=1)            # one seeded run
print(result.outputs["Final Account Value"])
print(result.summary[["Age (you)", "Federal", "State"]].head())

monteCarlo = runIterations(inputs, iterations=250, seed=1)
print(monteCarlo.median, monteCarlo.typical, monteCarlo.shareDepleted)

claimAt70 = dataclasses.replace(inputs, you=dataclasses.replace(inputs.you, socialSecurityAge=70))
table = compareTable(compareScenarios({"claim early": inputs, "claim at 70": claimAt70}, iterations=250, seed=1))
print(table)

  • saveInputs and loadInputs write and read JSON configs. A file from an older version upgrades when it loads.

  • loadScenarioUpgrading saves the upgraded config at once and keeps the original in .backup/.

  • Limits and refusals, such as list sizes and non-finite numbers, are in ../reference/api.
